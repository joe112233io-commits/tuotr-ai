# TutorAI

Next Level AI Tutoring for Life-Long Learners. Rebuilt as a modern React SPA with TypeScript, Tailwind CSS, and Google GenAI integration.

## Features
- **Custom AI Course Generation**: Create personalized courses on any topic with interactive outlines, modules, and lessons.
- **Multilingual Support (EN / AR)**: Full bilingual experience with complete Arabic RTL support.
- **Interactive Study Tools**: Lessons, 4-question quizzes with instant answer checking, spaced repetition flashcards, and AI tutor chat.
- **AI Homework Helper**: Step-by-step problem solver for homework questions.
- **Library & Progress Tracking**: Save courses to your personal library and track lesson completion.
- **AI Provider Settings**: Configure built-in Google Gemini or custom OpenAI-compatible / Anthropic / Ollama API keys.

## Development
- Run `npm run dev` to start the development server on port 3000.
- Run `npm run build` to build for production.
